# 行测数量关系学习助手

一个用于行测数量关系刷题与下一题推荐的学习项目。先从「工程问题」开始：整理题目、记录作答、定位薄弱点，再逐步实现分层提示与针对性补练。

## 当前阶段

仓库刚建立，功能尚未实现。开发会按每周三、周六的小任务推进；每次根据实际提交的代码和运行结果调整下一步。

第一步是设计一条题目的结构化表示，并手工整理少量可核对的工程问题样例。后续再逐步加入答题记录、推荐规则和简易界面。
